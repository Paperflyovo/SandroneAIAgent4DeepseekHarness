# Sandrone Harness V26.9.30 LTS

本发布为 **长期支持（LTS）稳定版**，版本号 `26.9.30`，Git 标签 `v26.9.30-lts`。

代码基线是 `25de646`（原 `release: Sandrone Harness V26.9.12`）。这是 2026-09-30 起对 Harness 运行时的两轮大幅升级（`0.1.5-rc.1`、`0.2.0-rc.2`）**之前**的最后一个稳定状态，因此本版不含那两轮改动。

> 与 `V26.9.12` 的代码完全一致。当时发布页漏发了这一版对应的构建产物，本版为补发，并把版本号推进到 `26.9.30` 以便与 LTS 标签对应。

| 组件 | 版本 |
|---|---|
| `@deepseek-ai/dsh` 包族 | `0.1.1-rc.1`（8 个补丁） |

## 功能

与 `V26.9.12` 相同：

- 桌面版侧栏 **工作区 / 空间区** 双区域；空间区提供子空间与 Markdown 的创建、编辑/阅读切换、自动保存、资源导入与相对链接跳转。
- Sandrone 暖纸张与墨色视觉层，可切换深色模式，紧凑侧栏，Buddy 宠物。
- 无边框窗口与自绘标题栏（文件/编辑/视图/帮助）。
- 内置网页浏览功能已移除。
- 会话长截图的选区校验、分块合成、超时处理及保存/附件状态反馈。

空间数据保存在用户数据目录下的 `space/`；早期版本放在应用安装目录的数据会在首次启动时自动复制到新位置，原目录保留不删除。

## 安装

下载 **SandroneAIAgent-26.9.30-x64.exe**，双击安装后从桌面或开始菜单启动。

安装包自带 Electron、Node 运行时、Harness、界面资源及 Windows 原生组件，启动应用不需要单独安装 Node.js、pnpm、Python 或克隆源码。首次启动完成预览提示后，可填写 API Key 或选择“稍后配置”；模型对话需要可用的提供商和网络。Agent 操作的项目如需 Git、Python、编译器等工具，请按项目要求安装。

安装包未签名，Windows 可能显示 SmartScreen 提示。请从本仓库下载，并对照附件 **SHA256SUMS.txt** 核验文件。正常升级保留本机用户数据。

## 与后续版本的关系

`V26.9.30 LTS` 之后的版本会把 Harness 运行时升级到 `0.2.0-rc.2`（含 `0.1.5-rc.1` 的全部改动）。升级首次启动前会自动备份本机 Harness 数据到 `DeepSeekHarness-backups/before-0.2.0-rc.2-*/data`，备份失败会停止启动；回退步骤见适配层 README 的 *Upgrade backup and rollback*。

需要长期稳定、且不需要新版 Harness 能力的用户建议停留在本 LTS 版。
